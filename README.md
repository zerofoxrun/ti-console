# TI Console — расширение для Firefox ESR

Рабочее место TI-аналитика: разбор отчётов на индикаторы, дерево
инструментов, кейс, скелет отчёта. Всё считается **локально, в браузере,
без сети и без сервера**.

> **С чего начать:** `LOCAL.md` — установка и приёмка ·
> `АРХИТЕКТУРА.md` — устройство расширения · `CHANGELOG.md` — что менялось

---

## Чего здесь нет и не будет

Сервера в проекте нет. Серверная часть, метапоиск, база кейсов, анализ
моделью и конвейер их развёртывания **в этот репозиторий не выкладываются**
и расширению не требуются: разбор, дерево инструментов, кейс и экспорт
работают полностью автономно.

Расширение никогда не отправляет индикатор, содержимое страницы или
контекст инцидента куда-либо: ни автоматически, ни по кнопке.

## Что можно потрогать

### 1. Расширение в Firefox (временная загрузка)

```
about:debugging#/runtime/this-firefox
  → «Загрузить временное дополнение» → extension/manifest.json
```

Появляется подменённая новая вкладка, кнопка на панели (разбор открытой
страницы с подсветкой индикаторов), боковая панель, контекстное меню
на выделенном тексте.

Временное дополнение живёт до перезапуска браузера; подпись не требуется.

### 2. Расширение в Chrome

```
python3 tools_build_ext.py --chrome        # соберёт dist/chrome-unpacked
chrome://extensions → режим разработчика → «Загрузить распакованное»
```

Манифест под Chrome **выводится** из манифеста Firefox, вручную второй
не ведётся. Чего в Chrome нет — показа IP открытого хоста: в Firefox он
делается резолвом средствами самого браузера, в Chrome такого API нет,
а внешний сервис означал бы отправку имени расследуемого хоста наружу.
Кнопка не прячется, а отключается с объяснением.

### 3. Что проверить за минуту

1. Вставить в поле разбора любой отчёт или лог → «Разобрать».
2. Убедиться, что `report.pdf` и `main.js` в индикаторы не попали,
   а `127.0.0.1` помечен `non-routable`.
3. Переключить «Режим данных» на «Клиентские данные» — публичные сервисы
   станут недоступны.
4. «Добавить в кейс» → вкладка «Кейс и отчёт» → «Скелет отчёта (MD)».

### 4. Тесты

```bash
node extension/lib/compat.test.js       # слой совместимости с Chrome
for f in extension/lib/*.test.js; do node "$f"; done
node extension/markup.test.js
node extension/background.test.js
node extension/newtab/fox.test.js
```

Сейчас это 924 проверки. Числа по файлам намеренно не расписаны: они
меняются, а разошедшийся список хуже отсутствующего.

### 5. Сборка

```bash
python3 tools_build_ext.py              # dist/ti-console.xpi + тема
python3 tools_build_ext.py --chrome     # dist/ti-console-chrome.zip
```

Каталог `dist/` в репозиторий не кладётся: там артефакты, которые
собираются из исходников.

## Структура

| Путь | Что это |
|---|---|
| `extension/manifest.json` | MV3 для Firefox. Архитектурные решения — в комментариях внутри файла |
| `extension/lib/ioc.js` | Ядро распознавания: 18 типов IOC, refang, склейка переносов, дедупликация, экспорт в STIX 2.1 |
| `extension/lib/noise.js` | Отсев обвязки: колонтитулы, раздел ссылок, контактные строки |
| `extension/lib/compat.js` | Слой совместимости с Chrome. Отсутствующие возможности **не подменяются заглушками** |
| `extension/data/tools.json` | Реестр инструментов с разметкой `exposure`, `activity`, `pricing`, `api` |
| `extension/newtab/` | Главная вкладка |
| `extension/panel/` | Боковая панель |
| `extension/content/scan.js` | Разбор открытой страницы с подсветкой |
| `extension/sw.js` | Точка входа фона в Chrome (в Firefox — `background.scripts`) |
| `theme/` | Тёмная тема браузера |
| `policies/policies.json` | Корпоративная политика Firefox ESR — каждый блок с обоснованием |
| `policies/policies-local.json` | То же без сервера. **Генерируется**, руками не править |
| `policies/make-local.py` | Генератор локальной политики из основной |
| `windows/firefox.cfg`, `windows/autoconfig.js` | AutoConfig: снятие требования подписи на ESR |
| `windows/check-install.ps1` | Проверка установки на машине аналитика |
| `tools/ti-update-check.ps1` | Диагностика: почему обновление не применилось |
| `tools/update_tlds.py` | Обновление списка TLD из Public Suffix List |
| `tools_build_ext.py` | Сборка XPI и варианта под Chrome |
| `LOCAL.md` | Развёртывание без сервера |
| `АРХИТЕКТУРА.md` | Для разработчика: что за что отвечает |

## Известные ограничения

Задокументированы в коде и покрыты тестами, здесь — коротко:

- Девять расширений файлов совпадают с настоящими TLD (`cab com map md
  mov pl py sh zip`). Общего правила нет; решение принято по каждому
  отдельно и записано в коде. Перекрывается дефангом: если автор отчёта
  написал `backup[.]zip`, спорить с ним нельзя.
- `1.0.0.4` синтаксически валидный IPv4 и будет распознан. Без контекста
  неразрешимо.
- Разбор по ссылке уходит с адреса аналитика: инфраструктура, которую
  вы проверяете, видит обращение. Под полем об этом написано, и убирать
  эту строку нельзя.
- В Chrome нет показа IP хоста — см. выше. Это не доработка, а граница:
  сделать иначе значило бы отправить имя хоста наружу.
